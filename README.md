# Neural Networks

A lightweight deep learning and neural network exploration repository featuring a tiny scalar-valued autograd engine and neural network library built from scratch (inspired by Andrej Karpathy's micrograd).

## Contents
- **`micrograd.ipynb`**: Implementation of scalar-valued autograd engine (`Value` class), automatic differentiation, graphviz computational graph visualization, and backpropagation through neural network layers.

## Requirements
- Python 3.10+
- `graphviz`
- `numpy`
- `matplotlib`

## Quick Start
```bash
# Install dependencies
pip install graphviz numpy matplotlib

# Install graphviz system package (macOS via Homebrew)
brew install graphviz
```
